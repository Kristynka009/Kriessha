# Kriessha

Z vašich fotek uděláme krátká videa, která můžete hned pustit jako reklamu na Instagramu a Facebooku.

Nástřel prezentačního webu (struktura inspirovaná [Hotmart](https://hotmart.com/en), barvy z naší palety).

## Spuštění ve Visual Studio Code

1. Otevři složku projektu: **File → Open Folder…** a vyber `Kriessha`.
2. V menu **Terminal → New Terminal**.
3. Jednou nainstaluj závislosti a spusť web:

```bash
npm install
npm run dev
```

4. V terminálu se objeví odkaz `http://localhost:5173` — klikni na něj se stisknutým **Ctrl** (nebo **Cmd** na Macu). Stránka se otevře v prohlížeči na celou obrazovku.

Příště už stačí jen `npm run dev`.

Nebo nahoře **Run → Start Debugging** (F5) — to spustí server a otevře Chrome.

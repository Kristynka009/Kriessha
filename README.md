# Kriessha

Z vašich fotek uděláme krátká videa, která můžete hned pustit jako reklamu na Instagramu a Facebooku.

Nástřel prezentačního webu (struktura inspirovaná [Hotmart](https://hotmart.com/en), barvy z naší palety).

## Spuštění

```bash
npm install
npm run dev
```
